## 4. Nội dung các bài thực hành

### Lab08 – JavaScript 1: Language Foundations

Tìm hiểu những kiến thức cơ bản của JavaScript như cách khai báo biến, kiểu dữ liệu, cấu trúc điều khiển, các đối tượng có sẵn, mảng, hàm và đối tượng. Qua đó, em hiểu cách sử dụng JavaScript để xử lý dữ liệu và xây dựng các chức năng cơ bản cho website.

### Lab09 – JavaScript 2: DOM and Events

Tìm hiểu cách sử dụng DOM để truy xuất và thay đổi các thành phần HTML. Thực hành xử lý sự kiện, thao tác với nội dung trang web, làm việc với biểu mẫu và kiểm tra dữ liệu người dùng nhập vào.

### Lab10 – JavaScript 3: jQuery

Làm quen với thư viện jQuery, cách sử dụng bộ chọn, xử lý sự kiện, thao tác với các phần tử DOM, tạo hiệu ứng chuyển động và gửi yêu cầu GET. Đồng thời, tìm hiểu cách xử lý kết quả trả về thông qua jqXHR.
